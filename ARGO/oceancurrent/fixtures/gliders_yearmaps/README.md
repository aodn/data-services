The six `.html`/`.gif` files retain their original upstream names and bytes:

- `2018_sg_temp_04d.html`, `2018_sg_temp.gif`
- `2025_sl_temp_04d.html`, `2025_sl_temp.gif`
- `2026_sl_temp_04d_nrt.html`, `2026_sl_temp_nrt.gif`

`catalogue.json` is generated with the existing parser from
https://oceancurrent.aodn.org.au/gliders/index.html on the same date, retaining
only records for these maps' 43 mission names and filtering all order lists to
those records. It includes the genuine catalogue coordinates for consistency
checks; no coordinates or processing versions were invented.

`expected.json` is the deterministic geographic index: 39 non-null deployment
bounds in the two Slocum maps, and four null bounds in the Seaglider map, which
has insufficient anchors/spread. The GIFs are retained only as visual reference
artwork for independent axis measurements. The generator and automated tests do
not need to open them; no GIF dimensions are published.

`frontend-reference.json` was generated by executing the original frontend's
`calibrateGliderMap` and `pixelToGeographic` functions under Node 24, using matched
rectangles and these actual catalogue coordinates. The source was recovered from
local frontend Git blob `c355b85c97ce503f3b88768e32d05e1081898d55` (the former
`src/utils/gliders-map-utils/georeference.ts`). It records coefficients, errors,
and unrounded bounds for all 39 successful deployments, plus the Seaglider
rejection. Python parity tests require no Node installation.

acceptance thresholds, supported layouts and the JSON URL contract.
